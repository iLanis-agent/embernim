# Embernim1.0 TEST
Native Java/Canvas Android8+ normal-play Nim against a deterministic optimal keeper. Three heaps,one to seven embers each. Remove any positive amount from one heap;the keeper replies. Whoever takes the last ember wins. Tap ember N to keep N-1,removing it and all to its right. Twelve player-winning starts,full-round undo/reset,saved palette/heap counts,GG007menu/site/privacy.

Independent recursive Java minimax checks all512states, confirms XOR characterization and optimal/legal keeper replies. Twelve full games using winning moves,full-round undo/replay,invalidmoves pass. Adapter navigation/settings/privacy/taps/persistence and pixels inspected. Not phone screenshots. Phone runtime/performance/browser-handoff QA incomplete. Not final or Play published.

Registry803 found no Nim/subtraction game. Unlike Stackflare prefix sorting,this is adversarial heap subtraction with an optimal opponent and last-object objective. Known Nim genre,not global invention.
